1 Vlož API klíč Technické nastavení

Klíč je potřeba pro tvorbu verzí, řešení a kontrolu kvality. Nastavení je schované, aby hlavní práce se zadáním zůstala nahoře přehledná.

⚡ Generování přes Gemini Klíč není nastaven
Pokročilé · kompatibilita P1

Trvalé ukládání klíče poskytovatele bylo odstraněno. Na školním serveru se klíč do prohlížeče vůbec neposílá.

Relace = klíč se po zavření prohlížeče sám zapomene. Každý kolega používá vlastní osobní API klíč; klíče se nesdílejí a nikdy se nevkládají do HTML na GitHubu. API klíč: aistudio.google.com → Get API key.

Při vyčerpání kvóty se postupně zkusí všechny záložní modely. Podmínky práce s daty se liší podle regionu a fakturace. U neplacených služeb mimo EHP, Švýcarsko a Spojené království může Google odeslaný obsah a odpovědi použít ke zlepšování produktů a mohou je kontrolovat lidští hodnotitelé. V EHP, Švýcarsku a Spojeném království se podle aktuálních podmínek na data vztahují pravidla placených služeb i u neplacené kvóty; aplikace zpřístupněná uživatelům v těchto regionech má používat projekt s aktivní fakturací. Vždy posílej materiály bez jmen a osobních či citlivých údajů žáků.

3 Zkontroluj zadání a vyber stupně Pedagogické nastavení

CEFR je vypnutý. Zapni ho jen tehdy, když jde o jazykový materiál.

U jazyků můžeš použít CEFR. U ostatních předmětů jde jen o úroveň obtížnosti.

Chceš přesnější výstup? Volitelně doplň cílovou skupinu, čas, typ nové varianty, míru zachování struktury nebo vlastní pokyn učitele.
Pedagogické zpřesněnívolitelné, ale doporučené pro přesnější diferenciaci

Tato část je volitelná. Výchozí automatika ponechává aplikaci univerzální: u Normální verze typicky vytvoří paralelní variantu se stejnou obtížností, u Jednodušší/Obtížnější verze více drží původní obsah a mění míru opory nebo výzvy.

↘ Vyber úroveň nové verze

Vybraná verze je rychlá volba pro jeden konkrétní účel. Celá sada vytvoří Jednodušší, Normální i Obtížnější variantu ze stejného zadání. Při vytváření celé sady vzniknou všechny tři verze ze stejného obsahu a liší se jen mírou opory. Pokud chceš paralelní variantu s jiným obsahem, použij v Pedagogickém zpřesnění volbu „Stejný formát, jiný obsah“. Znak „+“ znamená, že při nedodržené JSON struktuře může aplikace výjimečně použít jeden opravný dotaz navíc pro každou verzi.

Kontrola před PDF

Tato verze ještě neprošla kontrolou kvality. Před stažením PDF je vhodné zkontrolovat věcnou správnost, jazyk, zadání i řešení.

Doporučený postup: nejdřív spusť Kontrolu, oprav případné chyby a teprve potom stáhni PDF. AI kontrola ale není garance správnosti; finální odpovědnost má učitel. Pokud už jsi text zkontroloval ručně, můžeš pokračovat bez AI kontroly.
