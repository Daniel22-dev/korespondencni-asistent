Korespondenční asistent

Pomůže skrýt citlivé údaje před odesláním k modelu. Rozbor a odpověď, nebo oprava, přepis a sestavení tvého textu — vždy s povinnou kontrolou náhledu. Před každým odesláním ověř, že v textu nezůstala skutečná jména ani jiné citlivé údaje.

Pokročilé · bezpečné uložení

P1 nepovoluje trvalé ukládání klíče poskytovatele. Po zavření prohlížeče se klíč zapomene.

Relace = klíč se po zavření prohlížeče sám zapomene. API klíč: aistudio.google.com → Get API key.

Aplikace používá pouze profil Úsporný / Doporučený / Důkladný. Konkrétní model vybírá aktivní AI transport.

Fakturace a práce s daty

V serverless režimu se používá osobní Gemini API klíč. Ve školním režimu vybírá konkrétní model školní AI služba. Do AI vždy posílej pouze ručně zkontrolovaný anonymizovaný náhled.

Bezpečnostní příprava · vše v jednom kroku

Zkontroluj anonymizovaný text před odesláním

E-maily a telefony aplikace skryje automaticky. V jednom velkém poli označíš jména a vlastní názvy a zároveň vidíš hlavní anonymizovaný obsah. Před odesláním aplikace zkontroluje i poznámku, volby a celý sestavený prompt.

2Anonymizace a hlavní obsah pro AI model

Klikni přímo na slovo nebo označ více slov. V pevném panelu napravo zvolíš osobu, instituci, místo, název / dílo, kontakt, jiný citlivý údaj nebo ponechání. Bezpečné zbývající návrhy lze po přečtení ponechat hromadně. Žlutá značka už je anonymizovaná; kliknutím ji znovu odkryješ.

Před odesláním pročti celý text.Ověř, že neobsahuje skutečná jména, kontakty ani jiné osobní nebo citlivé údaje. Zobrazený text je hlavní částí zadání. Před API se znovu prověří také poznámka, zvolené parametry a celý sestavený prompt.
Klikni na výraz v textu, kategorii zvol napravo a potom text ještě jednou celý přečti.
Hlavní anonymizovaný obsahPřed odesláním se k němu přidají pouze bezpečně zkontrolované volby a poznámka.

Hlavní úkol: skryj skutečné identifikátory, ostatní návrhy vyřeš jednotlivě nebo hromadně a pročti celý odesílaný text. Tabulka náhrad zůstává sbalená níže pro případ ruční opravy.
