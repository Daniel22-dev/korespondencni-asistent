# Diferenciátor 1.3.8 — audit reportéru a platformní integrace

Verze **1.3.8** zachovává kanonický reportér GHRAB 1.1.0 a jeho neblokující spuštění. Etapa P2 doplňuje GHRAB Platform 1.0.0, jednotné logo, motivový kontrakt, Studio Bridge v2, namespacované úložiště, standardní service worker a kontrolovaný formát přenositelných projektů.

## Ověření

- právě jedna instance reportéru;
- selhání adaptéru neblokuje start aplikace;
- pět snímků, ZIP diagnostika v3, Gmail URL do 7 000 znaků;
- focus trap a nové reportId pro nové hlášení;
- zdrojová i distribuční kopie odpovídá společnému kanonickému souboru.
