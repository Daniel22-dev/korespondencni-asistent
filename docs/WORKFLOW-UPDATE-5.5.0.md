# Korespondenční asistent 5.5.0

- Profil odesílatele je viditelný přímo v pracovním toku a ukládá roli, vyučované předměty a školu. Jméno zůstává jen pro místní podpis.
- Rychlé rozpoznání je transparentní místní heuristika bez dalšího API requestu.
- Samostatná volba počtu adresátů rozlišuje jednotlivce a hromadný e-mail.
- Školní scénář je volitelné přednastavení a ukazuje změněné parametry.
- Pokročilé sekce se zobrazují jen pro relevantní akce.
